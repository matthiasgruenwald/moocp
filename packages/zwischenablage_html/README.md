# zwischenablage_html

Legt HTML und Text zugleich in die Zwischenablage, damit Strg+V in einem Editor formatiert einfügt. Teil von moocp, nicht auf pub.dev.

Nativ umgesetzt ist derzeit nur Windows (Format „HTML Format" und `CF_UNICODETEXT`). Auf anderen Plattformen legt `alsHtmlKopieren` nur den Text ab.
